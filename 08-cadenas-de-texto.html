CADENAS DE TEXTO (STRINGS)

Comando Efecto
var="str"
var='str'		 Crea un string y lo almacena en una variable
$str3=$str1$str2 Concatena dos strings y los guarda en una variable. Nótese que no lleva espacios
${#str} Devuelve la longitud del string
${substr:ind:cant} Extrae un substring que comienza en el índice ind. El parámetro cant es opcional e indica la cantidad de caracteres que abarca
${str/substr} Elimina la primera ocurrencia del substring indicado
${str//substr} Elimina todas las ocurrencias del substring indicado
${str/substr1/substr2} Reemplaza el substr1 por el substr2 (sólo reemplaza a la primera ocurrencia)
${str,} (una sola coma) Modifica el primer caracter del string a minúsculas
${str^} (un solo acento circunflexo) Modifica el primer caracter del string a mayúsculas
${str,,} (dos comas) Modifica todos los caracteres del string a minúsculas
${str^^} (dos acentos circunflexos) Modifica todos los caracteres del string a mayúsculas

Con las cadenas de texto se pueden utilizar tanto las comillas simples (') como las dobles ("), pero no siempre tienen el mismo efecto:

  • Las comillas simples tratan al contenido de forma literal.
  • Las comillas dobles permiten incluir variables de por medio.

Por ejemplo, el comando echo ¡Hola, $usuario! tendrá resultados diferentes si se usa una u otra:

$usuario='José'

echo '¡Hola, $usuario!'     # ¡Hola, $usuario!
echo "¡Hola, $usuario!"     # ¡Hola, José!

Ejercicios

  1. Guardar el siguiente string en una variable y imprimir por consola su longitud: "El elefante y la ballena azul son los mamíferos más grandes." (incluido el punto).
  2. Guardar en otra variable el siguiente texto: "[espacio]El elefante es el mayor de los terrestres, pero la ballena azul es más grande de todos."
  3. Concatenar ambos textos almacenándolos en una variable nueva e imprimir nuevamente su extensión.
  4. Extraer e imprimir por consola el substring mamíferos más grandes.
  5. Eliminar sólo la primera ocurrencia de elefante.
  6. Reemplazar mamíferos por animales.
  7. Eliminar todas las ocurrencias de ballena azul.
  8. Crear una variable con el valor serpiente y modificar todas sus letras a mayúsculas.
  9. Crear una variable con el valor delfín y convertir su inicial a mayúsculas.
