ARRAYS

NOTA: A diferencia de algunos lenguajes de programación, los arrays en Bash pueden contener datos de distintos tipos.
Comando Efecto
arr=(item1 item2...) Crea un array
${arr[n]} Accede al elemento de índice n del array [1]
${arr[*]} Retorna todos los elementos del array
${#arr[@]} Retorna el tamaño del array (la cantidad de elementos)
arr[n]=nuevo Reemplaza el elemento de índice n por uno nuevo
arr+=(nuevo) Agrega un elemento nuevo al final del array
unset arr[n] Elimina el elemento de índice n del array
unset arr Borra TODOS los elementos del array, dejándolo vacío

[1] Al igual que en la mayoría de los lenguajes de programación, el primer índice es cero (0).

Ejercicios

  1. Directamente en la consola, crear un array con al menos 5 nombres de frutas y luego imprimir todos sus elementos y su tamaño.
  2. Imprimir el tercer elemento.
  3. Reemplazar el segundo elemento por una fruta nueva.
  4. Agregar una nueva fruta al final del array.
  5. Borrar el cuarto elemento.
  6. Crear un nuevo array con al menos 2 elementos de distinto tipo (un número y un string, por ejemplo).
