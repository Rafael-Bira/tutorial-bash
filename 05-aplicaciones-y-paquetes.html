APLICACIONES Y PAQUETES

Mayormente las aplicaciones que se instalan o desinstalan desde la terminal requieren permisos de administrador, por lo que casi siempre van precedidas del comando sudo.

Comando Efecto
apt install paq
apt-get paq		 Instala una aplicación. [1]
apt search paq Busca un paquete por su nombre
apt install ruta/paq.deb Instala un paquete .deb ya descargado
apt remove paq Elimina los paquetes de una aplicación
apt purge paq Elimina todos los paquetes, configuraciones y archivos de una aplicación
apt update paq Actualiza un paquete o aplicación
apt-cache search paq Busca un paquete y brinda una descripción breve
apt-cache show paq Muestra el contenido de un paquete
apt clean Remueve paquetes incompletos
apt autoclean Libera espacio en el disco vaciando el caché
apt autoremove Remueve paquetes que ya no sean necesarios

[1] apt (advance packaging tool) es el comando para distros basadas en Debian (Ubuntu, Linux Mint); para las basadas en Red Hat (Fedora, CentOS) es yum y para las basadas en Arch (Manjaro) es pacman -s (sin install).

Ejercicios

  1. Buscar en caché el paquete nsnake.
  2. Instalarlo desde consola.
  3. Salir y actualizarlo a su versión más reciente.
  4. Desinstalarlo.
  5. Quitar automáticamente los paquetes que ya no sean necesarios.
