ARCHIVOS Y DIRECTORIOS

Lo primero que debemos tener siempre presente es que en Linux todo es un archivo, desde las unidades de disco duro y extraíbles hasta los directorios. De hecho, un directorio es un tipo especial de archivo que almacena la dirección en memoria de los archivos y/o subdirectorios que contenga.

Ya vimos que las rutas pueden ser absolutas o relativas: son absolutas cuando comienzan desde el root (/) y pueden ser referenciadas desde cualquier lugar del sistema, y son relativas cuando dependen de la ubicación actual. En las rutas es muy común encontrar un punto (.) o dos puntos seguidos (..): el primero refiere a la ubicación en donde estamos ahora y el segundo se refiere al directorio padre.

Otro punto fundamental es que (a diferencia de otros sistemas operativos tales como Windows, donde la extensión es importante porque le indica al sistema qué tipo de archivo es) Linux simplemente ignora la extensión del archivo y se fija en su contenido para determinar de qué tipo es. De esta forma, a un archivo .jpg se le podría cambiar su extensión a .txt y aún así el sistema Linux lo seguiría tratando como a una imagen.

Comando Efecto
whereis (where is?) Busca la ubicación de un archivo ejecutable. Si están disponibles, retorna también su fuente y manual
cd ruta (change directory) Cambia a la ruta indicada, sea absoluta o relativa
cd Vuelve al directorio de inicio (home)
cd .. Sube un nivel en los directorios. ../.. sube dos niveles, ../../.. sube tres y así sucesivamente
cd ../dir Sube un nivel y enseguida ingresa a otro subdirectorio
cd - Muestra en pantalla el directorio anterior y regresa a él
mkdir dir
mkdir dir1 dir2 "dir_nuevo"...		 (make directory) Crea uno o varios directorios en la ubicación actual [1]
mkdir -v (-view) Muestra un mensaje sobre el directorio creado
mkdir dir && cd $_ Crea un directorio y cambia inmediatamente a él
mkdir dir{01,02,03...} Crea directorios con igual nombre y distinto sufijo (dir01, dir02, dir03...)
mkdir dir{A..D} (dos puntos) Crea 4 directorios con igual nombre y distinto sufijo: dirA, dirB, dirC y dirD
mkdir -p subdir1 subdir2... (-parent) Crea uno o varios subdirectorios
mkdir dir1/dir2/dir3... Crea subdirectorios anidados
touch arch
touch arch1 arch2 "arch_nuevo"...		 Crea uno o varios archivos en la ubicación actual [1]
touch arch{01,02,03...} Crea archivos con igual nombre y distinto sufijo: arch01, arch02, arch03...
touch arch{A..D} (punto punto) Crea 4 archivos con igual nombre y distinto sufijo: archA, archB, archC y archD
touch -m arch (-modify) Actualiza la fecha de modificación del archivo a la actual
./arch
bash arch		 Ejecuta un archivo
du -h arch (disc use -human-readable) Muestra el tamaño que ocupa un archivo o directorio
locate arch Busca un archivo según su nombre
file arch Muestra una descripción breve del tipo de archivo
find ruta -name nom -type tipo Busca un archivo o directorio con cierto nombre dentro de un directorio dado. La opción -type especifica el tipo: d para directorios, f para archivos
grep expr arch Busca una expresión determinada en cierto archivo
cp arch_orig arch_nuevo (copy) Copia un archivo y crea uno nuevo
cp arch1 arch2 arch3... ruta Copia el o los archivos y los pega en un directorio dado. [2]
cp -i arch ruta (-interactive) Copia el archivo y lo pega en un directorio dado, pidiendo confirmación
cp * Copia todo el contenido del directorio actual
cp -r dir1 dir2... dir_dest (-recursive) Copia el o los directorios y los pega en otro
cp -r dir_orig/. dir_dest Copia solamente el contenido del directorio y lo pega en otro
rmdir dir (remove directory) Borra un directorio sólo si está vacío
rmdir -v dir (-verbose) Borra un directorio y muestra un mensaje
rm arch (remove) Borra un archivo del directorio actual
rm ruta/arch Borra un archivo de la ruta indicada
rm -r -i arch (-recursive -interactive) Borra el archivo, pidiendo confirmación
rm -r -f dir (-force) Fuerza el borrado del directorio.
ATENCIÓN: Debe tenerse muchísimo cuidado con la opción -rf porque no pide confirmación ni arroja error si el directorio no existe.
mv arch1 arch2... ruta (move) Mueve uno o varios archivos desde el directorio actual a otro directorio de destino
mv ruta_orig ruta_dest Mueve un archivo o directorio desde ruta_orig a ruta_dest
mv arch nom_nuevo Renombra el archivo o directorio
basename ruta Extrae el nombre de una carpeta o de un archivo con su extensión
basename ruta .ext Extrae el nombre de un archivo SIN su extensión
basename -a *.ext (-all) Muestra todos los archivos del directorio actual que tengan cierta extensión
basename -s .ext -a *.ext (-suffix) Muestra todos los archivos del directorio actual que tengan cierta extensión, SIN su extensión
unzip arch.zip Descomprime un archivo zip
zip -r comp.zip arch1 arch2... (-recursive) Comprime archivos y directorios con sus contenidos en uno con extensión zip
zip -x comp.zip arch1 arch2 -x arch3 (-exclude) Comprime los archivos arch1 y arch2 y excluye a arch3
zip -d comp.zip arch1 arch2... (-delete) Borra archivos y directorios de un archivo zip.
ATENCIÓN: NO borra los directorios si NO están vacíos
zip -e comp.zip arch1 arch2... (-encrypt) Comprime varios archivos en un archivo zip, pidiendo una contraseña para descomprimirlo
cat arch (concatenate) Visualiza el contenido de un archivo sin la necesidad de abrir un editor
cat -n arch (-number) Visualiza el contenido de un archivo mostrando los números de línea
cat > arch Crea un archivo nuevo e inmediatamente permite escribir su código
cat arch1 arch2 > arch3 Concatena dos archivos y lo guarda como un archivo nuevo
tac arch (cat invertido) Muestra el contenido del archivo pero invertido, imprimiendo desde la última línea hasta la primera

[1] Se deben usar comillas si el nombre tiene más de una palabra.

[2] Si ya existen archivos con el mismo nombre, se sobreescribirán.

Filtros

Afortunadamente, la consola cuenta con varios comandos nativos para filtrar el contenido de los archivos:

Comando Efecto
wc -w (word count -words) Muestra la cantidad de palabras en el archivo
wc -l (-lines) Muestra la cantidad de líneas del archivo
wc -m Muestra la cantidad de caracteres en el archivo
head arch Muestra las primeras 10 líneas de un archivo
head -n cant arch Muestra las primeras líneas de un archivo, desde la primera hasta la cantidad indicada
tail arch Muestra las últimas 10 líneas de un archivo
tail -n +cant arch Muestra las últimas líneas de un archivo, desde la cantidad indicada hasta el final
sort arch Ordena alfabéticamente las líneas del archivo
nl arch (number lines) Muestra el archivo con las líneas numeradas
nl -w num arch Muestra el archivo con las líneas numeradas. La opción -w indica la cantidad de espacios de indentación
nl -s str arch Muestra el archivo con las líneas numeradas. La opción -s (-string) señala una cadena de texto que se imprimirá luego del número. Por ejemplo, con -s ' - ' se mostrará:
1 -
2 -
 ...

Operadores de redirección

Los operadores de redirección permiten enviar la salida de un comando a un archivo, o bien leer desde un archivo como entrada para un comando.

Operador Efecto
com > arch Toma la salida del comando y lo guarda en un archivo
com >> arch Añade la salida del comando al final del archivo
com < arch Lee el contenido del archivo y lo utiliza como entrada para el comando

Operador >

El operador "mayor que" (>) envía la salida de un comando a un archivo. Por ejemplo:

ls -1 > lista.txt     # Guarda la lista de archivos y directorios actuales en un archivo de texto

Operador >>

El operador >> agrega la salida del comando al final del archivo, sin borrar el contenido anterior.

echo "Esta es una línea nueva" >> lista.txt     # Agrega una nueva línea al final del archivo de texto

Operador <

Al contrario que >, el operador "menor que" (<) lee el contenido de un archivo para un comando. La diferencia con | radica en que éste conecta dos comandos entre sí, mientras que el operador < conecta un archivo directamente a un comando.

wc -m < lista.txt     # Cuenta la cantidad de caracteres en un archivo de texto
