ARCHIVOS Y DIRECTORIOS

Lo primero que debemos tener siempre presente es que en Linux todo es un archivo, desde las unidades de disco duro y extraíbles hasta los directorios. De hecho, un directorio es un tipo especial de archivo que almacena la dirección en memoria de los archivos y/o subdirectorios que contenga.

Ya vimos que las rutas pueden ser absolutas o relativas: son absolutas cuando comienzan desde el root (/) y pueden ser referenciadas desde cualquier lugar del sistema, y son relativas cuando dependen de la ubicación actual. En las rutas es muy común encontrar un punto (.) o dos puntos seguidos (..): el primero refiere a la ubicación en donde estamos ahora y el segundo se refiere al directorio padre.

Es muy común que los nombres de los archivos contengan espacios, por lo que es importante usar comillas dobles (") al referenciarlos en la terminal. Por ejemplo: "mi archivo.txt".

Otro punto fundamental es que, a diferencia de otros sistemas operativos tales como Windows, donde la extensión es importante porque le indica al sistema qué tipo de archivo es, Linux simplemente ignora la extensión del archivo y se fija en su contenido para determinar de qué tipo es. De esta forma, a un archivo .jpg se le podría cambiar su extensión a .txt y aún así el sistema Linux lo seguiría tratando como a una imagen.

Filtros

Afortunadamente, la consola cuenta con varios comandos nativos para filtrar el contenido de los archivos:

Comando Efecto
wc -w (word count -words) Muestra la cantidad de palabras en el archivo
wc -l (-lines) Muestra la cantidad de líneas del archivo
wc -m Muestra la cantidad de caracteres en el archivo
head archivo Muestra las primeras 10 líneas de un archivo
head -n número archivo Muestra las primeras líneas de un archivo, desde la primera hasta la cantidad indicada
tail archivo Muestra las últimas 10 líneas de un archivo
tail -n +número archivo Muestra las últimas líneas de un archivo, desde la cantidad indicada hasta el final
sort archivo Ordena alfabéticamente las líneas del archivo
nl archivo (number lines) Muestra el archivo con las líneas numeradas
nl -w número archivo Muestra el archivo con las líneas numeradas. La opción -w indica la cantidad de espacios de indentación
nl -s cadena archivo Muestra el archivo con las líneas numeradas. La opción -s (-string) señala una cadena de texto que se imprimirá luego del número. Por ejemplo, con -s ' - ' se mostrará:
1 -
2 -
 ...

Operadores de redirección

Los operadores de redirección permiten enviar la salida de un comando a un archivo, o bien leer desde un archivo como entrada para un comando.

Operador Efecto
comando > archivo Toma la salida del comando y lo guarda en un archivo
comando >> archivo Añade la salida del comando al final del archivo
comando < archivo Lee el contenido del archivo y lo utiliza como entrada para el comando

Operador >

El operador "mayor que" (>) envía la salida de un comando a un archivo. Por ejemplo:

ls -1 > lista.txt     # Guarda la lista de archivos y directorios actuales en un archivo de texto

Operador >>

El operador >> agrega la salida del comando al final del archivo, sin borrar el contenido anterior.

echo "Esta es una línea nueva" >> lista.txt     # Agrega una nueva línea al final del archivo de texto

Operador <

Al contrario que >, el operador "menor que" (<) lee el contenido de un archivo para un comando. La diferencia con | radica en que éste conecta dos comandos entre sí, mientras que el operador < conecta un archivo directamente a un comando.

wc -m < lista.txt     # Cuenta la cantidad de caracteres en un archivo de texto

Truncar, extender y dividir archivos

Existen dos comandos útiles para manipular el tamaño de los archivos: truncate y split.

Comando Descripción
truncate -s tamaño archivo (-size) Recorta o extiende un archivo a un cierto tamaño
split -b tamaño archivo prefijo (-bytes) Divide un archivo en varias partes según un tamaño dado
split -n número archivo prefijo (-number) Divide un archivo en cierto número de partes

truncate

Este comando nos permite tanto truncar como extender un archivo según su tamaño actual. Por defecto, el tamaño está indicado bytes, pero también se puede especificar en kilobytes con el sufijo K, en megabytes con M, en gigabytes con G, etc.

truncate -b 100K archivo.txt     # Extiende el archivo a 100 kilobytes (si su tamaño es menor)

split

El comando split divide un archivo en varias partes. La opción -b indica el tamaño de cada parte, mientras que la opción -n indica la cantidad de partes en que se dividirá el archivo. Por defecto, los archivos resultantes se nombran con una secuencia de letras (aa, ab, ac...), pero se pueden utilizar números con la opción -d.

split -b 250K archivo.txt fragmento-      # Divide el archivo en partes de 250 kilobytes. Los nombres de las partes serán "fragmento-aa", "fragmento-ab", etc.
split -b 2M -d archivo.txt parte_         # Divide el archivo en partes de 2 megabytes. Los nombres de las partes serán "parte_00", "parte_01", etc.
split -n 6 archivo.txt parte_             # Divide el archivo en 6 partes iguales
